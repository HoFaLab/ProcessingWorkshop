## 🛠️ Nützliche Code-Schnipsel

### Zufällige Farbe bei Klick
```java
void mousePressed() {
  background(random(255), random(255), random(255));
}
```

### Ball prallt an Wänden ab
```java
float x = 300, y = 200;
float speedX = 3, speedY = 2;

void draw() {
  background(255);
  ellipse(x, y, 30, 30);
  
  x += speedX;
  y += speedY;
  
  if (x > width || x < 0) speedX *= -1;
  if (y > height || y < 0) speedY *= -1;
}
```
